about=Multi-Encode Vector Converter is a QGIS plugin designed to solve character encoding issues (e.g., garbled special characters or accents) when converting vector data, such as Shapefiles, to GeoPackage (GPKG), ensuring safe data integration. It allows you to preview attribute data before conversion, specify the correct encoding from a wide range of standard Python encodings (e.g., UTF-8, Windows-1252, ISO-8859-1), and output a standard UTF-8 GeoPackage. It also supports joining external CSV files with different encodings during the conversion process. Support: https://paypal.me/rawslnc

changelog=
    1.0.1: Restructure the panel into "Convert" and "Description" tabs to keep vertical height manageable when the QGIS UI font size is enlarged; remove the outer "Conversion Steps" group box so A/B/C sit directly in the Convert tab; replace the old "Important Note" text with a Description tab explaining when to use the plugin and concrete caveats (e.g. GPKG conversion cannot restore data already lost to the old Shapefile 10-character field name limit); move the language switcher to a fixed bottom-left row outside the tabs; fix language switching not updating the already-rendered encoding preview and execution result labels; mark the plugin as no longer experimental
    1.0.0: QGIS 4.x (PyQt6/Qt6) support. Replaced the QDockWidget-based panel with a plain modeless QDialog window (same approach as webodm_importer/shinrinbo_code_converter) to keep the plugin out of Qt6's dock/float transition handling, which was forcing the panel to detach into floating mode on every open; tightened the Join key row so the two field-selector combos sit flush against the "=" separator instead of stretching apart. Security scan cleanup: vendor a minimal defusedxml (matching forestry_operations_lite) and use it for all .xlsx XML parsing instead of raw xml.etree.ElementTree; annotate the remaining intentional except/pass fallbacks with justified nosec B110
    0.2.2: Fix bandit security scan warning: suppress intentional bare-except fallback in layer source path parsing with nosec B110
    0.2.1: Fix join field subset check to treat empty list as "all fields" (prevents silent data loss when joinFieldNamesSubset returns []); fix _flatten_to_memory to apply GPKG reserved name protection for non-SHP layers
    0.2.0: Add CRS-undefined warning dialog; fix GPKG layer name mismatch on auto-load; remove duplicate overwrite confirmation; add progress bar during conversion (non-blocking UI); add ja/es/pt translations for new strings
